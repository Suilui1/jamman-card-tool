Auf GitHub veröffentlichen
==========================

Vorbereitet ist alles: Der Ordner jamman-card-tool ist ein Git-Repository
mit einem ersten Commit. Es fehlen nur noch zwei Dinge, die nur du tun
kannst: das Repository auf GitHub anlegen und den Spendenlink einsetzen.

1. Spendenlink einsetzen (optional, aber gewollt)

   In jamman.py, Zeile:

       SPENDEN_LINK = ""

   Adresse zwischen die Anführungszeichen, zum Beispiel:

       SPENDEN_LINK = "https://paypal.me/deinname"

   Danach in README.md und README.de.md den Abschnitt "Support" bzw.
   "Unterstützen" anpassen. Solange der Link leer ist, zeigt der Knopf
   "Spenden" im Fenster einen Hinweis.

2. Repository auf GitHub anlegen

   Auf https://github.com/new ein neues Repository erstellen:
     Name:        jamman-card-tool   (oder wie du willst)
     Sichtbarkeit: öffentlich
     KEIN README, KEINE .gitignore, KEINE Lizenz ankreuzen -
     all das liegt schon im Ordner.

3. Hochladen

   Im Terminal:

       cd <Pfad>/jamman-card-tool
       git remote add origin git@github.com:Suilui1/jamman-card-tool.git
       git branch -M main
       git push -u origin main

   Mit HTTPS statt SSH:

       git remote add origin https://github.com/Suilui1/jamman-card-tool.git

4. Danach prüfen

   - Öffnet die Startseite, und sind die Bilder im README zu sehen?
   - Steht im Reiter "Actions" nichts Rotes? (Es ist keine CI eingerichtet,
     also sollte dort nichts laufen.)
   - Sind keine Audiodateien, Karteninhalte oder Sicherungen dabei?
     (Die .gitignore hält *.wav und testcard/ draußen.)

Was NICHT ins Repository gehört
-------------------------------

- Audiodateien der Karte (*.wav) - die .gitignore verhindert es.
- Sicherungen (~/JamMan-Sicherung) - stehen nicht im Ordner.
- Persönliche Pfade - geprüft, keine im Code.

Wenn später etwas geändert wird
-------------------------------

       cd jamman-card-tool
       git add -A
       git commit -m "Kurze Beschreibung"
       git push

Die Fassung steht in jamman.py in der Zeile FASSUNG und wird von
"jamman.py --version" ausgegeben. Bitte bei jeder Änderung mitpflegen und
in CHANGELOG.md eintragen.
